# Development

The website uses Next.js App Router, React, and TypeScript. Node.js 22 or later is required.

```sh
npm ci --ignore-scripts
npm run dev
```

The development site runs at <http://127.0.0.1:4173>.

```sh
npm run check
npm run build
npm run preview
```

Next.js exports the website to `out/`. The preview command serves those production files; `next start` does not apply to static export mode.

## Project entries

Follow the project showcase rules in `AGENTS.md` before adding or synchronizing projects. Edit `lib/projects.json` to add a reviewed project. Each entry shares its ID, category, visual color, and verified product and/or public source links. The `content.en` and `content.zh` objects contain its translated name, label, headline, description, tags, and action. Both translations are required. Categories are `desktop`, `web`, `extension`, and `play`.

Counts and category filters use that data. Missing links are omitted. Private repositories must not be linked. Add original illustrations in `lib/illustrations.ts` where appropriate; artwork must remain checked-in source rather than API-provided HTML.

## Languages

English is the default at `/en/`; Simplified Chinese lives at `/zh/`. Root requests redirect to English through Cloudflare's `_redirects` file. Locale pages are statically generated by `app/[locale]/`, with localized HTML language, descriptions, canonicals, and alternate-language links. Shared UI copy is in `lib/i18n.ts`. Language links preserve the current section hash.

## Deployment

The production domain is <https://agentclub.dev>. GitHub Actions validates changes and keeps the former GitHub Pages root redirected to this domain. Explicit locale paths on GitHub Pages serve the same export for public visual verification. Cloudflare Workers Static Assets serves the Next.js export using `wrangler.jsonc`.

```sh
npm run deploy
```

Authenticate using Wrangler's normal login flow. Never commit credentials, local sessions, environment files, or Cloudflare tokens. The deployment uploads `out/` only.

## Design notes

The original structure was informed by Linear and Resend. The updated palette uses warm porcelain surfaces, ink-blue text, and electric-blue accents. Vercel’s light surface hierarchy and Raycast’s selective accent treatment informed this color study. Agent Club's identity, orbital art, and product illustrations are original. Card illustrations contain synthetic demonstration content; they are not product screenshots. The illustrated calendar is not a holiday schedule and the QR drawing is not a functional code.

The animation respects reduced-motion preferences, supports explicit pause, and stops drawing when hidden or outside the viewport. The website includes no third-party fonts, tracking scripts, or runtime API requests.
